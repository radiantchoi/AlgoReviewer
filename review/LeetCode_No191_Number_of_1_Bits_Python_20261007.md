# LeetCode No.191 Number of 1 Bits Code Review

## 코드 리뷰 — LeetCode 191. Number of 1 Bits

```python
class Solution:
    def hammingWeight(self, n: int) -> int:
        return n.bit_count()
```

### 시간 복잡도
- Python의 `int.bit_count()`를 사용해 `n`의 1 비트 개수를 계산합니다.
- LeetCode의 입력은 32비트 정수이므로, 입력 크기를 고정하면 **O(1)**입니다. 비트 수를 `k`로 일반화하면 **O(k)**로 볼 수 있습니다.
- 비트를 직접 반복해서 세는 방법보다 간결하고, 별도의 알고리즘 최적화가 필요하지 않습니다.

### 공간 복잡도
- 별도의 자료구조를 만들지 않으므로 **O(1) 보조 공간**입니다.

### 정석 풀이와 비교
대표적인 비트 연산 풀이인 **Brian Kernighan 알고리즘**은 다음과 같습니다.

```python
count = 0
while n:
    n &= n - 1
    count += 1
```

매 반복마다 가장 낮은 위치의 1 비트를 제거하므로, 시간 복잡도는 **O(1의 개수)**입니다. 이 문제는 32비트 정수로 입력 크기가 제한되어 있고 Python의 `bit_count()`가 이를 직접 제공하므로, 현재 풀이가 더 간단하고 적절합니다. DP나 그래프 접근은 이 문제에 필요하지 않습니다.

### 적절성 및 엣지 케이스
- `n == 0`이면 `bit_count()`가 `0`을 반환하므로 올바르게 처리됩니다.
- LeetCode의 입력 조건인 **0 이상 32비트 정수**에서는 정확합니다.
- Python에서 음수에 `bit_count()`를 적용하면 고정 폭 2의 보수 표현의 비트 수가 아니라 **절댓값의 1 비트 개수**를 계산합니다. 음수도 입력으로 허용되는 문제라면 이 동작이 요구사항과 맞는지 확인해야 합니다.

### Python 스타일
- `int.bit_count()`를 활용한 매우 간결하고 관용적인 Python 코드입니다.
- Python 3.10 이상에서 사용할 수 있으므로, 실행 환경이 해당 버전 이상인지 확인하면 됩니다.

**총평:** 문제의 입력 조건과 Python 버전이 맞다면, 간결하고 효율적인 정답입니다.
